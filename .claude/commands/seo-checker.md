# seo-checker: SEO 점검 에이전트

블로그 콘텐츠의 검색 엔진 최적화 상태를 점검합니다.

## 입력
- 대상 파일 또는 "all": $ARGUMENTS (미지정 시 전체 검사)

## 점검 항목

### 1. frontmatter 필수 필드 검사
모든 `content/*.md` 파일에 대해:
- [ ] `title` 존재 여부 (50~60자 권장)
- [ ] `date` 존재 여부
- [ ] `tags` 존재 여부 (최소 1개)
- [ ] `description` 존재 여부 (없으면 자동 생성 제안, 150~160자 권장)

### 2. 콘텐츠 품질 검사
- [ ] H1 제목 중복 없는지 확인
- [ ] 첫 문단에 핵심 키워드 포함 여부
- [ ] 이미지에 alt 텍스트 존재 여부
- [ ] 내부 링크(위키링크) 최소 2개 이상 포함 여부
- [ ] 글 길이 최소 300단어 이상인지

### 3. URL/슬러그 검사
- [ ] 파일명에 공백 포함 여부 (URL 인코딩 문제)
- [ ] 파일명 길이 적정성 (60자 이내)
- [ ] 특수문자 포함 여부

### 4. 기술적 SEO 검사
- `quartz.config.ts`에서:
  - [ ] `pageTitle` 설정 확인
  - [ ] `baseUrl` 올바른지 확인
  - [ ] `description` 플러그인 활성화 여부
- `ContentIndex` emitter에서:
  - [ ] sitemap 생성 활성화 여부
  - [ ] RSS 피드 활성화 여부

### 5. 출력 형식
```
## SEO 점검 결과

### 통과 ✅ (N개)
- file1.md: 모든 항목 통과

### 경고 ⚠️ (N개)
- file2.md: description 누락, 내부 링크 부족

### 실패 ❌ (N개)
- file3.md: title 누락, 파일명 공백 포함

### 개선 제안
1. {구체적 수정 제안}
```
