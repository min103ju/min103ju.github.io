# backlink-analyzer: 백링크 & 그래프 분석 에이전트

블로그의 위키링크 구조를 분석하고 연결성을 개선합니다.

## 입력
- 대상 파일 또는 분석 모드 (graph/orphan/suggest): $ARGUMENTS (기본: graph)

## 분석 모드

### 1. graph: 전체 링크 구조 분석
`content/` 디렉토리의 모든 마크다운 파일에서:
- `[[위키링크]]` 패턴을 추출
- 각 파일의 발신 링크(outgoing)와 수신 링크(incoming) 집계
- 링크 관계를 인접 리스트로 구성

출력:
```
## 그래프 구조 분석

### 허브 노트 (수신 링크 상위 5개)
| 파일 | 수신 링크 | 발신 링크 |
|------|----------|----------|
| {파일} | N | N |

### 링크 매트릭스
- 총 노드: N개
- 총 엣지: N개
- 평균 연결 수: N개
- 최대 연결 수: N개 ({파일})
```

### 2. orphan: 고립된 노트 탐지
- 다른 글에서 링크되지 않은 글 목록
- 위키링크를 하나도 포함하지 않는 글 목록
- 양방향 모두 연결 없는 완전 고립 노트

출력:
```
## 고립된 노트

### 수신 링크 없음 (N개)
- {파일}: 발신 링크 N개 있으나 아무도 참조하지 않음

### 발신 링크 없음 (N개)
- {파일}: 다른 글에 대한 링크 없음

### 완전 고립 (N개)
- {파일}: 연결 전무
```

### 3. suggest: 링크 추가 제안
기존 콘텐츠를 분석하여:
- 제목/태그 유사도 기반으로 연결 가능한 글 쌍 추천
- 같은 태그를 공유하지만 위키링크가 없는 글 탐지
- 구체적인 위키링크 삽입 위치와 텍스트 제안

출력:
```
## 링크 추가 제안

### 높은 관련성 (같은 태그 + 내용 유사)
1. [[글A]] ↔ [[글B]]: "{공통 키워드}" 관련
   - 글A {N}번째 줄 근처에 `[[글B]]` 추가 제안

### 중간 관련성 (같은 태그)
1. [[글C]] → [[글D]]: 태그 "{태그}" 공유
```

## 주의사항
- 위키링크 형식: `[[파일명]]` 또는 `[[파일명|표시텍스트]]`
- 파일 확장자(.md)는 위키링크에 포함하지 않음
- content/ 하위의 .md 파일만 분석 대상
