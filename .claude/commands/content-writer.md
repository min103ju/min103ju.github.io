# content-writer: 블로그 콘텐츠 작성 에이전트

Quartz 블로그의 콘텐츠를 작성하는 에이전트입니다.

## 입력
- 주제 또는 키워드: $ARGUMENTS

## 작업 절차

### 1. 기존 콘텐츠 분석
- `content/` 디렉토리의 기존 글 목록을 확인하여 Day 넘버링 파악
- 기존 글의 frontmatter 패턴과 문체를 분석

### 2. frontmatter 생성
```yaml
---
title: "{제목}"
date: "{오늘 날짜 YYYY-MM-DD}"
tags:
  - {관련 태그 2~4개}
---
```

### 3. 본문 작성 규칙
- Obsidian Flavored Markdown 사용
- 위키링크(`[[관련 글]]`)로 기존 콘텐츠와 연결
- 콜아웃 블록(`> [!tip]`, `> [!warning]`) 적극 활용
- 코드 블록에 언어 지정 필수
- 한 섹션은 3~5문단, 전체 글은 200~400줄 목표
- Mermaid 다이어그램으로 구조/흐름 시각화 권장

### 4. 파일 저장
- 파일명: `content/Day{N}_{주제_요약}.md`
- 파일명에 공백 대신 언더스코어 사용
- 한글 파일명 허용하되 특수문자 제외

### 5. 연결성 확인
- 기존 글에서 새 글로의 위키링크 추가 제안
- 관련 태그가 기존 태그 체계와 일관되는지 확인
