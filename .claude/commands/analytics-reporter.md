# analytics-reporter: 분석 리포트 에이전트

블로그의 콘텐츠 현황과 구조를 분석하여 리포트를 생성합니다.

## 입력
- 분석 유형 (summary/detail/growth): $ARGUMENTS (기본: summary)

## 분석 항목

### 1. 콘텐츠 현황 분석
`content/` 디렉토리를 스캔하여:
- 총 게시글 수
- 최근 작성/수정된 글 (Git 이력 기반)
- 글 평균 길이 (단어 수)
- 태그별 글 분포
- 월별/주별 작성 빈도

### 2. 연결성 분석
- 위키링크 총 개수
- 글당 평균 위키링크 수
- 가장 많이 참조되는 글 (인기 허브)
- 고립된 글 (링크 없는 노트) 목록
- 태그 사용 빈도 순위

### 3. 기술 현황
- Quartz 버전 정보
- 활성화된 플러그인 목록
- 빌드 설정 요약
- 배포 상태 (최근 커밋 이력)

### 4. 성장 지표 (growth 모드)
Git 이력을 분석하여:
- 주간/월간 커밋 빈도
- 콘텐츠 증가 추이
- 가장 활발한 작성 시간대

### 5. 출력 형식
```
## 블로그 분석 리포트 ({날짜})

### 콘텐츠 현황
- 총 게시글: N개
- 총 태그: N개
- 평균 글 길이: N단어
- 최근 수정: {파일명} ({날짜})

### 태그 분포
| 태그 | 글 수 |
|------|------|
| {태그} | N |

### 연결성
- 위키링크 총 N개 (글당 평균 N개)
- 허브 글: {가장 많이 참조되는 글}
- 고립된 글: {목록}

### 개선 제안
1. {구체적 제안}
```
